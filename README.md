# 证研 · 投资命题验证

面向需要核验公司投资判断的个人研究者。输入一个命题，确认必要条件，再检查支持、反对和无法验证的证据。当前提供可本地运行的源代码和验证材料；公开网站部署尚待验收，不将 localhost 地址作为已上线产品 URL。

## 产品流程

1. 首页输入命题，下方展示最近三项研究；同一研究的历史版本聚合。
2. AI 根据研究方向与缺失条件生成澄清问题。明确的信息不重复询问，条件充分时直接继续。
3. 展示只读研究概览：修订命题、范围与判断标准、待验证子问题。
4. 获取真实数据与材料，形成结论、图表、三类证据、冲突处理和结论变更条件。
5. 悬停引用编号查看材料标题，点击可用原文链接打开原文；没有原文的结构化数据明确标注。
6. 普通追问保留在当前版本。调整条件、补充材料或更新数据后重新验证，保存为同一研究的新版本。

结果不按证据数量投票，不将“尚未验证”当作反证，也不将扣非利润直接等同于主营利润。

## 本地运行

需要 Node.js >=22.13.0，推荐 Node.js 24。数据服务和模型密钥由运行者自行申请。

```sh
npm ci
```

复制 `.dev.vars.example` 为 `.dev.vars`，填入 `FUYAO_API_KEY`、`IFIND_MCP_KEY`、`DEEPSEEK_API_KEY`。密钥仅用于后端，不要提交真实文件。当前模型为已通过账户接口核验的 `deepseek-flash`，请求显式关闭思考模式并使用 JSON 输出。

```sh
npm run db:setup
npm run dev
```

打开终端打印的本地地址，默认 `http://127.0.0.1:5173/`。数据库初始化命令只操作本地 D1，不部署云端。更新迁移后可再次运行；已有研究不会因此被清空。

```sh
npm test
npx tsc --noEmit
npm run build
```

代码使用 Vinext/React、Cloudflare Workers、D1 和 Recharts。图表模块只在浏览器加载，避免 Worker 服务端承担图表库的初始化。云端运行依赖 D1 绑定 `DB`，以及上述后端环境变量；迁移文件位于 `drizzle/`。当前 `.openai/hosting.json` 保留已有 Sites 项目标识，后续发布不得另建项目或将本地预览误报为公开 URL。

## AI 的角色与验证

- `lib/planning.ts`：专门的澄清/规划提示，按盈利、股价估值、产业链方向识别必要条件；整合用户答案后重新生成命题和子问题。
- `lib/engine.ts`：程序获取数据、解析数值与单位并计算指标；AI 整理结论、判定证据方向、关联子问题、提出冲突和变更条件。
- `lib/research-analysis.ts`：分析遵循“观察—解释—替代解释/边界”，另一次模型复核收紧因果跳跃并移除未获证据支持的分析。复核使用相同模型，不是独立来源或正确性保证。毛利增量桥接由程序计算，不冒充销量、价格或归母利润归因。
- `app/api/chat/route.ts`：仅依据当前研究中的已核验事实和指标解释问题，未核验材料只能提示缺口。
- 程序检查结论、追问和子问题回答中的证据 ID；ID 合法不等于语义一定正确，仍需核对原始数据和原文。
- 模型失败时保留已取得材料，明确标为未完成；不会用历史样例替代一次失败的真实请求。

模型调用日志只记录模型名、完成原因和 token 用量，不打印密钥。接口验证与人工原文核对用于约束 AI 输出，不把 AI 自我检查当作独立验证。

## 数据

| 来源 | 当前使用 | 关键口径 |
|---|---|---|
| 扶摇 | 公司检索、利润表、资产负债表、现金流量表、区间日线 | 财务金额为元；季报为累计值；价格使用前复权并注明实际首末交易日 |
| iFinD MCP | 指定报告期扣非利润、指定日期 PE、公告线索、行业指标候选 | 按单元格亿/万归一；严格匹配代码和日期；摘要不等于原文 |
| 官方年报 | 已核验的贵州茅台2024年报索引 | 对应数值匹配后提供真实链接和页码；同一披露不重复视为独立来源 |
| 用户补充材料 | 文本摘录、来源链接和页码 | 标为未独立核验，不自动升级成已确认事实 |

图表读取研究快照中的实际数值，不由模型编造。快照保留来源、获取时间、适用期间和原始返回。原文固定索引注明核验日期，不伪装成本次重新下载。

## 保存与访问

- 以高熵 HttpOnly Cookie 识别匿名浏览器会话，服务器保存 owner 的哈希。
- 读取研究、创建子版本和追问均检查所属会话；拒绝跨站写入。
- 版本编号按研究根 ID 分配，旧快照保留；追问不递增版本号。
- 产品未设置每日研究、规划或追问次数上限。上游服务自身的限流和余额约束仍可能导致调用失败，页面按具体服务显示错误。
- 清除 Cookie 或更换设备不能直接恢复历史记录；可导出 Markdown 研究报告。

## 边界与未做事项

- 当前支持 A股单公司年度比较、或最新可得累计财报与上年同季度累计比较；不支持任意区间财务归集、同年环比和多公司合并归因。
- 最新返回财报不等于历史时点可得版本，不能据此回放当时市场知道什么。`report_date_ms` 不直接用作首次披露日。
- 原文覆盖尚有限，不保证每家公司、每项数据都有可定位 PDF。无法取得时明确说明，不构造来源 URL 或原文截图。
- 产业链方向目前主要获取候选指标、识别传导证据缺口；没有完整的成本暴露、合同传导与分部利润因果模型。
- 尚无通用 PDF 上传解析、OCR、登录账号、跨设备同步、团队协作和定时跟踪。
- 研究引擎由已有数据能力和研究方向约束，不能任意执行 AI 提出的所有工具或验证所有金融命题。
- 不提供买卖建议、确定性收益承诺或自动交易。

本地 `?review=plan` / `?review=result` 仅供开发验收，使用明确标记的历史记录；相关接口在生产构建中返回404。

## 验证说明

源内测试覆盖引用协议安全、原文数值匹配和版本聚合。真实接口回归另覆盖澄清与确认、年度与累计报告期、区间行情、结论引用、版本保存与旧版保留、追问、会话隔离和父版本隔离。发现过季报 `limit` 超限，已修正为服务允许的上限并复测；图表在浏览器延迟加载后重新检查页面。

AI 使用与验证记录、测试说明及关键结论溯源作为单独附件提交，不包含在公开仓库中。仓库的 `tests/` 保留可运行的代码测试。

本地验证通过不代表云端数据服务已验证。视频由候选人录制，仓库未包含已录制视频；公开网站部署与线上验收需要另行完成。
